# قالب عمومی فروشگاه کاتالوگی

این پروژه عمداً **هیچ محصول، دسته‌بندی، برند یا تصویرِ مربوط به حوزه خاصی ندارد**. برای فروشگاه‌های مختلف قابل استفاده است؛ از پوشاک و لوازم خانه تا محصولات دیجیتال یا هر کالای دیگر.

## شروع سریع
1. فایل‌ها را در یک مخزن GitHub قرار دهید.
2. در `assets/js/config.js` نام فروشگاه، توضیحات، شناسه تلگرام، واحد پول و رنگ‌ها را تنظیم کنید.
3. فایل `data/products.json` در ابتدا خالی است. محصولات را از پنل Pages CMS اضافه کنید یا مستقیماً در JSON بنویسید.
4. تصاویر را در `assets/images/products/` قرار دهید و مسیرشان را در فیلد تصویر وارد کنید.
5. مخزن را با GitHub Pages منتشر کنید.

## مدیریت محصولات با Pages CMS
- وارد Pages CMS شوید و مخزن را متصل کنید.
- فایل `.pages.yml` تنظیمات ویرایش `data/products.json` را معرفی می‌کند.
- برای هر محصول یک `id` یکتا وارد کنید.
- `category` آزاد است؛ دسته‌بندی‌ها از روی محصولات موجود به‌صورت خودکار ساخته می‌شوند.
- `brand`، `image` و `description` اختیاری‌اند.
- برای ناموجود کردن محصول، `available` را خاموش کنید.

## سفارش تلگرام
این قالب ربات تلگرام یا درگاه پرداخت ندارد. با کلیک روی «ثبت سفارش در تلگرام»، متن سفارش در گفت‌وگوی شناسه‌ای که در `telegramUsername` تنظیم کرده‌اید باز می‌شود؛ مشتری باید خودش پیام را ارسال کند.

## نکته مهم
این قالب یک کاتالوگ ساده است و پرداخت آنلاین، حساب کاربری، موجودی انبار پیشرفته یا پنل سفارش‌های سمت سرور ندارد.
